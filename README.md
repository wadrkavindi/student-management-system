# Student Management System

## Project Description

The Student Management System is a Python desktop application developed using Tkinter and SQLite. It allows users to manage student information through a simple graphical user interface.

## Features

* Add new student records
* View all students in a table
* Search students by Student ID, name, or email
* Update existing student information
* Delete student records
* Validate user inputs
* Automatically calculate student grades
* Store student records in an SQLite database
* Clear input fields and display all student records

## Technologies Used

* Python
* Tkinter
* SQLite
* Visual Studio Code
* Git and GitHub

## Project Structure

* `main.py` — Main application and graphical user interface
* `database.py` — Database operations
* `student.py` — Student data model
* `students.db` — SQLite database file, created when the application runs
* `README.md` — Project documentation

## Requirements

* Python 3 installed on your computer
* Tkinter support

## How to Run

1. Download or clone this repository.

2. Open the project folder in Visual Studio Code.

3. Open a terminal in the project folder.

4. Run the following command:

   ```bash
   python main.py
   ```

5. The Student Management System window will open.

## Database

The application uses SQLite to store student information, including Student ID, name, email, course, and marks.

## Purpose

This project was developed to practise Python programming, object-oriented programming, database management, and graphical user interface development.
